About the workshop

VERTEX'26 in one page

The idea

  • A hands-on IoT workshop. Participants start with one blinking LED and finish with all teams playing one networked game.
  • Organised by the IEEE Robotics and Automation Society Student Branch Chapter of IIT.

  • ESP32 DevKit V1 board

  • A buzzer and jumper wires
  • USB data cable
  • A laptop with Arduino IDE 2, plus VS Code for Practical 4
  • A smartphone and the workshop Wi-Fi (2.4 GHz)

Practical 1 · LED control

Blink an LED

Learn: pinMode, digitalWrite, delay, and why a named constant helps

const int LED_PIN = 23; void setup() {  pinMode(LED_PIN, OUTPUT);} void loop() {  digitalWrite(LED_PIN, HIGH);  delay(1000);   digitalWrite(LED_PIN, LOW);  delay(1000);}
ESP32
GPIO 23
220 Ω
LED
  • Wiring: GPIO 23 → 220 Ω resistor → LED long leg. Short leg → GND.
  • Expected: ON 1 s, OFF 1 s, repeat.
  • Challenges: 500 ms blink · ON longer than OFF · another GPIO

setup() runs once. loop() repeats forever. HIGH = 3.3 V = LED on. The resistor protects the LED.

Practical 2 · Buzzer control

Switch an active buzzer

An active buzzer beeps by itself when powered: ON or OFF, one fixed pitch

const int BUZZER_PIN = 23; void setup() {  pinMode(BUZZER_PIN, OUTPUT);} void loop() {  digitalWrite(BUZZER_PIN, HIGH);   // buzzer on  delay(500);  digitalWrite(BUZZER_PIN, LOW);    // buzzer off  delay(1000);}
ESP32
GPIO 23
Buzzer
  • Wiring: buzzer signal (+) → GPIO 23. Buzzer (−) → GND.
  • Expected: beeps 500 ms, silent 1 s, repeat.
  • Note: check the buzzer’s current needs; use a driver if too high.

Practical 3 · Tone generation (optional)

Make sounds of different pitch

Needs a passive buzzer. Frequency (Hz) sets the pitch. Included only if time allows.

void loop() {  tone(BUZZER_PIN, 500);   // 500 Hz, lower pitch  delay(500);  noTone(BUZZER_PIN);  delay(200);   tone(BUZZER_PIN, 1000);  // 1000 Hz, higher pitch  delay(500);  noTone(BUZZER_PIN);  delay(1000);}

Active or passive?

  • Active buzzer (Practicals 2 and 4): beeps by itself when powered.
  • Passive buzzer (Practical 3 only): needs tone(pin, Hz) to sing.
  • Participants must use the type they were given.

Challenges: try 250, 500 and 1500 Hz · a 3-note sequence · a short melody

Task B · Catch LED 2

template.ino · PART 4 and PART 3 (shortened)

server.on("/control", HTTP_GET, handleControl);  // the buttons void handleControl() {  String device = server.arg("device");   // the data after  device=   e.g. "led1"  String state  = server.arg("state");    // the data after  state=    "on" or "off"   int pin = -1;  if (device == "led1") pin = LED1_PIN;  else if (device == "led2") pin = LED2_PIN;     // Task B  else if (device == "led3") pin = LED3_PIN;  else if (device == "buzzer") pin = BUZZER_PIN;  ...  if (state == "on") digitalWrite(pin, HIGH);  else digitalWrite(pin, LOW);

Participants do

  • Find the line for LED 1 in handleControl()
  • Copy it and change it to:
    else if (device == "led2") pin = LED2_PIN;

Key idea

The address /control runs handleControl(). server.arg() reads the two values, the name picks the pin, and digitalWrite switches it. The name in the page and the name here must match.

Practical 4 · Help at the table

Common problems and quick checks

ProblemWhat to check
Cannot join Wi-FiName and password · 2.4 GHz network · read Serial Monitor
Page does not openUse the exact address · same network · client isolation off
Page opens but nothing changesWiring · GPIO numbers · names “device” and “state”
Phone shows “Unknown device: led2”Task A is done but Task B is missing
Buzzer wrongBuzzer type · polarity · driver if needed
Sketch does not compileESP32 board support installed · ESP32 board selected · core version

Safety

  • This page has no password. Use it only on the workshop network, never on the open internet.
  • Disconnect USB before changing wiring.
  • Never use an LED without a resistor.
